# WebAssembly ツール

このプロジェクトは、WebAssembly モジュールを TypeScript アプリケーションに統合する方法を示すための WebAssembly ツールです。WebAssembly モジュールを読み込み、初期化するためのシンプルなセットアップを提供します。

## プロジェクト構成

- `src/index.ts`: アプリケーションのエントリーポイント。このファイルで WebAssembly モジュールを読み込み、必要な初期化を行います。
- `src/draw.ts`: 描画ロジックを実装するファイル。色、線種、線の太さを変更できるお絵描きツールのロジックを含みます。
- `src/wasm/module.wasm`: アプリケーションロジックを実装する WebAssembly モジュール。
- `tsconfig.json`: TypeScript のコンパイルオプションや対象ファイルを指定する設定ファイル。
- `package.json`: npm の設定ファイルで、プロジェクトの依存関係やスクリプトを記載しています。
- `webpack.config.js`: Webpack の設定ファイルで、モジュールのバンドル方法や出力設定を定義します。
- `dist/index.html`: アプリケーションの HTML ファイル。お絵描きツールの UI を提供します。

## はじめに

このプロジェクトを始めるには、以下の手順を実行してください。

1. リポジトリをクローンします:
   ```
   git clone <リポジトリURL>
   ```

2. プロジェクトディレクトリに移動します:
   ```
   cd webassembly-tool
   ```

3. 依存関係をインストールします:
   ```
   npm install
   ```

4. プロジェクトをビルドします:
   ```
   npm run build
   ```

5. アプリケーションを起動します:
   ```
   npm start
   ```

## 使い方

1. アプリケーションを起動すると、ブラウザにお絵描きツールが表示されます。
2. 以下の UI を使用して描画をカスタマイズできます:
   - **色**: カラーピッカーで線の色を変更できます。
   - **線の太さ**: 数値入力で線の太さを変更できます。
   - **線種**: ドロップダウンメニューで実線、点線、破線を選択できます。
3. マウスをドラッグしてキャンバス上に描画します。
